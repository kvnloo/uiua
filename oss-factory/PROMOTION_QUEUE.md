## Repro evidence and review follow-up

**Earlier wave's model-only reference harness:** [`oss-factory/evidence/reference_oracles.py`](https://github.com/kvnloo/uiua/blob/oss-factory/triage-2026-10-17/oss-factory/evidence/reference_oracles.py). Its recorded Python/NumPy/libm results were 30,000 deterministic FMA comparisons and 1,120 matrix cases with maximum absolute residual 1.2881e-12. These are historical mathematical-model results, not compiled Uiua acceptance; current native evidence above is separate.


1. **#1037:** f64 FMA `10.mul_add(-1.1, 11.0)` gives `-8.881784197001252e-16`; Euclidean remainder `11.0 % 1.1` gives `1.0999999999999992`. In a controlled synthetic sweep of **11,500** positive numbers/bases, **1,109** FMA residues fell outside `[0, base)`; this is NOT a representative workload or speed benchmark. The branch fixes the invariant via guarded fallback.
2. **#1036:** for `A = [[0,1],[1,0]]` and `B = [[1,2,3],[4,5,6]]`, a correct `AX=B` solution has shape `2×3` and rows `[[4,5,6],[1,2,3]]`; for identity `A` and column `B=[[7],[9]]`, output is `2×1`. The old algorithm indexed `B` with `n` columns regardless of `m` and always returned shape of `A`. Python/NumPy oracle validated these cases.
3. **#1031:** `dyadic_pervasive_inner` reversed operands when its RHS was a union; union-arm validation mutated `ch` on failed candidate; dynamic dimension inclusion incorrectly rejected `Dyn ⊇ Dyn`, and a union's subtype inclusion required exact variant equality instead of coverage. All four changes are isolated in downstream fork #6 with Rust tests.
4. **#1003:** requested invalid fixtures now run natively at forward/middle/reverse boundaries; both controls and same-runtime recovery pass. Original implementation credit remains with UnrelatedString; no guessed-error-message snapshots were added.
5. **#338/#1039/#1041:** actual browser/interpreter reproduction and recorded-head checks are complete. #338 uses the final rebuilt surface, #1039 passes faithful recursion programs, and #1041's corrected diagnostics still expose ordinary bounds errors. #1041 remains investigation-only pending general inverse semantics.
